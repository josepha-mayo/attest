The adversarial corpus, public. These are the Wycheproof-style conformance vectors every Attest verifier — browser JavaScript, stdlib Python, and AWS Lambda — must judge identically. Each row ships the real exported pack; verify → opens the browser verifier on it. A verifier that disagrees with the expected verdict is wrong, whatever surface it runs on. Five more vectors exercise issuer-document pinning and need a companion trust document — they live in the repo's tests/vectors/.

Verifier conformance vectors

The interesting rows aren't the obvious tampers — they're the grammar traps: leaf_index: true (a bool is an int subclass in Python, not an integer in JSON), "5" as a string, 5.5 fractional indices, space-padded hex, a tree_size of 240 that kills JS bitwise ops. These are the cases where two verifiers silently diverge — the corpus exists so ours can't.
